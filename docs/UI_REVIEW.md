# UI 및 Firebase 변경 검토

기존 앱은 React의 단일 `App.jsx`에서 화면·상태·API·통계를 관리하고 Spring Boot / H2 / Google OAuth 서버와 연결하는 구조였습니다. 반복되는 카드 그림자, 배경 그라데이션, 과한 굵기와 중복 로그인 안내가 정보의 위계를 흐렸습니다. 모바일의 세로 탭도 입력 화면 진입을 늦췄습니다.

## 변경

- 단색 배경과 얇은 구분선, 절제된 강조색으로 시각적 위계를 정리했습니다.
- 루틴 정보와 세트 입력을 나누고 실제 입력으로 계산하는 운동 요약을 추가했습니다.
- 세 화면의 탭을 모바일에서도 가로로 유지하고, 숫자 입력과 버튼 배치를 정돈했습니다.
- Firebase 인증·저장 모듈을 화면에서 분리했습니다. 회원 UID별 Firestore 경로를 사용하며 기본 운동 50개는 앱에 포함합니다.
- 그라데이션을 제거하고, 한국어 문서 제목·아이콘·키보드 포커스·모션 감소 설정을 정리했습니다.
- 블루·화이트 톤으로 배경과 표면을 통일했습니다. 네이비 글씨, 파란 버튼, 선명한 입력 테두리를 적용하고 9~11px의 보조 글자를 최소 12px로 키웠습니다. 흰 배경의 본문·보조 글자 대비는 각각 약 9.2:1·6.3:1이고, 흰 배경의 입력 테두리는 약 3.4:1입니다.
- 로컬 날짜를 사용해 한국 오전에 전날로 표시되는 문제를 수정했습니다. 비교 기록이 없을 때 변화율을 표시하지 않으며, 부위별 비율은 전체 세트 수를 기준으로 계산합니다.
- 로그아웃 전에 초안을 저장합니다. 제조사는 운동 기록 자체에 저장해 목록에서 기구를 삭제해도 남습니다.

## 검증

- 프론트 린트와 Firebase 운영 빌드 통과. 분리한 운영 번들도 브라우저에서 정상 로딩했습니다.
- 모델·날짜·숫자·기본 운동 호환성 테스트 8개 통과.
- 실제 Auth / Firestore 에뮬레이터의 저장소 CRUD 테스트 1개, 회원별 접근 규칙 테스트 7개 통과.
- 320 / 390 / 768 / 1440px에서 회원·비회원 × 3개 화면, 총 24개 조건에 가로 넘침 없음.
- UI의 기록 저장·수정·복제, 검색, 운동·세트 추가, 제조사 입력, 임시 저장 복구 확인.
- 실제 Firebase SDK를 사용하는 브라우저에서 생성·조회·수정·복제·삭제, 재접속 유지, 기구 숨김, 두 계정 사이의 기록·기구·초안 격리 확인. 콘솔 오류 없음.
- 설정 누락, 에뮬레이터 연결 상태, 배포 프로젝트 불일치 시 운영 배포 빌드를 차단하는지 확인했습니다.

로컬 브라우저 화면 검증은 테스트 계정과 예시 기록을 사용했습니다. Google 인증은 로컬 Auth 에뮬레이터의 Google 자격 증명으로 확인했습니다. 2026-10-14에 [운영 사이트](https://hellog-juno.web.app)를 배포하고 Google 제공업체 활성화, 서울 Standard Firestore, 회원별 규칙과 비로그인 접근 차단을 확인했습니다. 실제 사이트에서 모바일·데스크톱의 세 화면과 Google OAuth 페이지 연결도 확인했습니다. 실제 Google 계정으로 로그인한 뒤 기록을 저장하는 사용자 동작은 직접 확인하지 않았습니다. 기존 H2 기록은 자동 이전하지 않습니다.
